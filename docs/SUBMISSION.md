# Hello System submission checklist

- [ ] Add your student details to the project overview.
- [ ] Read and understand the source and defense notes.
- [ ] Run `python -m unittest discover -s tests -v`.
- [ ] Run the app and follow the demonstration in the overview.
- [ ] Capture Dashboard, Inventory, Reports, and a validation message for your submission.
- [ ] Submit PROJECT_OVERVIEW.md (or convert it to the format your instructor requests).
- [ ] Submit USER_GUIDE.md.
- [ ] Submit CODE_EXPLANATION.md.
- [ ] Create a GitHub repository and push the full source, tests, sample CSV, and docs.
- [ ] Paste the real GitHub repository URL into Hello System.
- [ ] For teamwork, add the actual division of responsibilities; otherwise mark individual work.

## Publishing the repository

Create an empty repository in your GitHub account. From the project folder, review files, commit, set its actual remote URL, and push. Do not publish `data/` or private inventory. `.gitignore` excludes local databases.

The repository is not published automatically by creating these files. A GitHub account and chosen repository destination are needed to complete this submission item.
